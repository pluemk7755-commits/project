# Roo Nai Gor Dai — สำหรับส่งผู้สอน (Private Repository เท่านั้น)

## คำเตือนข้อมูลส่วนบุคคล
ชุดนี้มีฐานข้อมูล SQLite เดิมพร้อมข้อมูลลูกค้า ประวัติการจอง สลิป และบัญชีรับโอน/QR จากโปรเจกต์เดิม ตามคำขอเจ้าของโปรเจกต์
**อย่านำขึ้น GitHub แบบ Public** ไม่แชร์ลิงก์กับผู้ที่ไม่ได้รับอนุญาต และอย่าทดลองโอนเงินจริงโดยไม่ตั้งใจ
บัญชี ADMIN ทดสอบอ่านได้ที่ `ข้อมูลสำหรับผู้ทดสอบ/บัญชี_ADMIN_สำหรับทดสอบ.txt` (เป็นบัญชีทดสอบเท่านั้น)

## วิธีเปิดใช้งาน
1. ติดตั้ง Python (แนะนำ 3.11–3.13; ตรวจสอบกับเครื่องของตัวเอง) แล้วเปิด Terminal ในโฟลเดอร์ที่มี `run.py`
2. รัน `python -m pip install -r requirements.txt`
3. รัน `python run.py` หรือ `start_web.bat` บน Windows
4. เข้าหน้าเว็บ `http://127.0.0.1:8000` และหน้า ADMIN `http://127.0.0.1:8000/staff/login`
5. บัญชีผู้ทดสอบดูจากโฟลเดอร์ `ข้อมูลสำหรับผู้ทดสอบ/`

## OTP / ลืมรหัสผ่าน — 2 วิธี (เลือกอัตโนมัติ)
- ทุกเครื่อง (รวมถึงเครื่องเจ้าของโปรเจกต์): เมื่อ `OTP_RELAY_URL` และ `TURNSTILE_SITEKEY` ตั้งค่าถูกต้อง โปรแกรม **เลือก Google Apps Script OTP relay + Cloudflare Turnstile ก่อน** แม้ยังมีค่า SMTP เดิมในเครื่อง
- เฉพาะเมื่อไม่ได้ตั้งค่าบริการ OTP ส่วนกลาง โปรแกรมจึงพยายามกลับไปใช้ SMTP ภายในเครื่อง (ต้องมีค่า SMTP ครบ) โดย `data/smtp.env` ต้องเก็บไว้เฉพาะเครื่อง และห้ามอัปโหลดขึ้น GitHub
- วิธีติดตั้ง OTP ส่วนกลาง: นำ `otp_service/otp_sender.gs` ไปตั้งค่าใน Google Apps Script โดยเจ้าของบัญชี Gmail กำหนด Script Properties `TURNSTILE_SECRET` และ `TURNSTILE_HOSTS` (ตัวอย่าง `localhost,127.0.0.1`) แล้ว Deploy เป็น Web app (Execute as Me, Anyone)
- สร้าง Cloudflare Turnstile widget ที่อนุญาต `localhost` และ `127.0.0.1` โดยใช้ Site Key สาธารณะและเก็บ Secret Key ไว้ฝั่ง Apps Script เท่านั้น
- แทนที่ `OTP_RELAY_URL` และ `TURNSTILE_SITEKEY` ใน `webapp/core.py` **ก่อนส่ง GitHub** ด้วยค่าจริงที่ไม่ใช่ความลับ
- เจ้าของโปรเจกต์ต้องทดสอบอีเมลจริงกับสำเนาที่ไม่มี smtp.env ก่อนส่ง จึงจะถือว่า OTP ใช้งานข้ามเครื่องได้
- บริการ OTP ส่วนกลางต้องมีอินเทอร์เน็ต อยู่ภายใต้โควตาของ Google และจำกัดจำนวนครั้งเพื่อป้องกันสแปม ไม่ได้รับประกันความพร้อมใช้แบบไม่จำกัด

## ระบบชำระเงิน
ชุดนี้เก็บ QR และบัญชีรับโอนเดิม; ADMIN ตรวจสลิปด้วยตนเอง ไม่ใช่ตรวจธุรกรรมธนาคารอัตโนมัติ การส่งสลิปไม่ได้หมายความว่าโอนเงินจริงแล้ว

## การทดสอบ
`python -m unittest discover -s tests -p "test_*.py" -v`
แนะนำให้ทดสอบบน **สำเนา** ของโฟลเดอร์ เพราะคำสั่งบางอย่างและหน้า ADMIN อาจแก้ฐานข้อมูลจริง

## GitHub
สร้าง Repo **Private** ก่อนอัปโหลด เปิดสิทธิ์ให้เฉพาะผู้สอน และตรวจว่า `data/smtp.env` ไม่อยู่ใน Git เสมอ
ไฟล์ `otp_service/otp_sender.gs` เป็นโค้ดสาธารณะ ไม่มี Secret Key; Secret เก็บใน Google Apps Script เท่านั้น

## การเตรียมส่ง GitHub และตรวจขั้นสุดท้าย
- ไฟล์ ZIP ชุดนี้จัดเก็บโค้ดและข้อมูลเดิมสำหรับผู้สอนแบบ **Private** โดยล้างเฉพาะเซสชันล็อกอิน รหัสรีเซ็ต และข้อมูลล็อกอินชั่วคราวที่หมดความจำเป็นแล้ว
- ก่อนใช้งานในเครื่องใหม่ เปิดโฟลเดอร์ `Roo-Nai-Gor-Dai` ที่มี `run.py` แล้วรัน `python -m pip install -r requirements.txt` และ `python run.py`
- หลังติดตั้งสำเร็จ ให้เข้า `/staff/login` ด้วยบัญชีทดสอบที่เตรียมไว้ ทดสอบฟอร์มจองและการแนบสลิปตัวอย่างตามคู่มือ
- **OTP จริง** ต้องใช้อินเทอร์เน็ต และบริการ Apps Script/Turnstile ของเจ้าของยังทำงานอยู่ จึงควรทดสอบจากเครื่องที่ไม่มี `smtp.env` หนึ่งครั้งก่อนส่ง
- **อย่าส่งไฟล์ ZIP ชุดนี้เป็น Public** เพราะมีข้อมูลผู้ใช้ สลิป ข้อมูลบัญชีรับโอน และบัญชีทดสอบ โปรดขออนุญาตผู้เกี่ยวข้องหากเป็นข้อมูลจริง
