Roo Nai Gor Dai — ข้อมูลเข้าระบบหลังร้านสำหรับผู้ทดสอบ

เปิดโปรแกรมด้วย python run.py ก่อน
หน้าเข้าสู่ระบบ ADMIN: http://127.0.0.1:8000/staff/login

บัญชี ADMIN สำหรับทดลองระบบ
ชื่อผู้ใช้ ADMIN: RakA.Lin
รหัสผ่าน ADMIN: aaaaaa

หากกรอกชื่อผู้ใช้หรือรหัสผ่าน ADMIN ไม่ถูกต้อง ระบบจะแสดงข้อความแจ้งเตือนและกลับไปที่หน้าเข้าสู่ระบบ ADMIN เพื่อให้ลองใหม่ได้

ข้อควรระวัง: บัญชี RakA.Lin ใช้สำหรับทดสอบเท่านั้น ห้ามนำรหัสผ่านทดสอบไปใช้กับระบบที่เปิดให้บุคคลทั่วไปเข้าถึง

ระบบลืมรหัสผ่านด้วย OTP ใช้กับบัญชีสมาชิกที่ลงทะเบียนอีเมลไว้ ไม่ได้ใช้บัญชี ADMIN เป็นบัญชีส่ง OTP
การทดสอบ OTP จริงต้องใช้อินเทอร์เน็ตและผ่าน Cloudflare Turnstile ก่อนส่งอีเมล
